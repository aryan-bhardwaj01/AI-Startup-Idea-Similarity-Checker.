# Sample ideas

Three ready-made startup ideas (each over 700 characters) to try in the app. Each `.txt` file holds only the description. Type the title and pick the domain from the table in the form, then paste the text, or load the file with the **Upload** button.

| # | Idea | Domain | File | Result (novelty) |
|---|---|---|---|---|
| 1 | MediBuddy, medicine reminders for elderly patients | Healthcare | [1-medibuddy-healthcare.txt](1-medibuddy-healthcare.txt) | 19, Crowded space |
| 2 | SkillBridge, job-readiness for engineering students | Education | [2-skillbridge-education.txt](2-skillbridge-education.txt) | 24, Crowded space |
| 3 | CraftLink, repair marketplace for retired craftsmen | Environment & Sustainability | [3-craftlink-environment.txt](3-craftlink-environment.txt) | 57, Some competition |
